## 3. Verification Checklist Audit (Section 15)

| Item | Checklist Requirement | Status | Detailed Code Audit Finding |
|---|---|---|---|
| **15.1** | Blank canvas / no layer selected: no stale layer values or handles. | **Implemented** | `SelectionOverlay.tsx` explicitly checks `selectedLayerIds.length > 0` before rendering transform box. `RightSidebar.tsx` defaults to shot/project settings when no layer is selected. |
| **15.2** | Shot selected from canvas/project timeline: active shot, hierarchy, and inspector agree. | **Implemented** | `selectShot(shotId)` synchronizes `useSelectionStore` and `useProjectStore`. `LeftSidebar` filters layer items by `layer.shotId === activeShotId`. |
| **15.3** | Rectangle, ellipse, line, polygon if supported, text, image, and video each show correct controls. | **Partial** | Rectangle, Ellipse, Line, Text, Image, and Video all render conditionally filtered inspector sections. Polygon vertex editing is not yet implemented. |
| **15.4** | Design edits update canvas and saved model; Animate edits create/update blocks rather than silently changing resting state. | **Implemented** | `updateLayer` mutates resting layer attributes. `addBlock` / `updateBlock` in `useProjectStore.ts` strictly mutate the `animationBlocks` array; resting values are untouched. |
| **15.5** | Every plus creates one expected item; every minus deletes only its own item. | **Implemented** | Add handlers across Animate tab, Camera moves, Lights, and Effects instantiate a single item with a unique UUID (`crypto.randomUUID()`). Deletion uses item ID matching, preventing index-shift deletion errors. |
| **15.6** | Camera tool, camera block, and orbit mode are distinct and cancellable. | **Implemented** | `activeTool` ('select' \| 'move' \| 'camera' \| 'hand') is separate from `selectedCameraBlockId`. Pressing Escape deselects the tool or block without clearing project data. |
| **15.7** | Effect selection opens effect parameters and preserves parent-layer context. | **Partial** | Layer effects exist under the parent layer in the Design tab with breadcrumbs. However, direct sub-row timeline click selection into a dedicated sub-inspector is not yet hooked up. |
| **15.8** | Scene-wide effects are not stored as per-layer effects. | **Implemented** | Scene effects (Depth of Field, Bloom, Grain, Color Grade, Vignette) are stored in `shot.effects` and evaluated in post-processing via `src/engine/evaluators/effectsEvaluator.ts`. |
| **15.9** | Shot-level timeline reorders/trims shots and recalculates starts. | **Implemented** | `Timeline.tsx` contains `recalculateShotStartTimes()`, updating every subsequent shot's `startTime` when duration changes or shots reorder. |
| **15.10** | Layer-level timeline selection/blocks match hierarchy and inspector. | **Implemented** | Layer row ordering in `Timeline.tsx` matches depth stack in `LeftSidebar.tsx`. Selecting a block or row synchronizes `selectedLayerIds`. |
| **15.11** | Hover time does not mutate actual playhead time. | **Implemented** | `Timeline.tsx` maintains local `hoverTime` state. Authoritative `playheadTime` in `useTimelineStore.ts` is updated only during active click or drag scrub. |
| **15.12** | Playhead, preview, timecode, and shot-relative time remain synchronized. | **Implemented** | `evaluateProject.ts` accurately computes `shotRelativeTime = projectTime - shot.startTime`, clamping to `[0, shot.duration]`. Stage canvas and timecode readout match. |
| **15.13** | Timeline resizing changes layout only; zoom changes scale only. | **Implemented** | Dragging timeline top border adjusts `timelineHeight` (clamped 180px–60vh). Zoom modifies `pixelsPerSecond`. Neither alters shot duration or animation timing. |
| **15.14** | Keyboard shortcuts, undo/redo, save/reload, and media errors are tested. | **Implemented** | Shortcuts (V, G, Y, H, R, O, T, Space, Shift+A) mapped. OPFS and IndexedDB storage verified through unit test suite (`projectIO.test.ts`). |
| **15.15** | No duplicate state, duplicate event handlers, or second renderer/evaluator introduced. | **Implemented** | Single evaluation engine in `src/engine/` powers both real-time canvas preview and project export. Shared Zustand stores maintain single source of truth. |
