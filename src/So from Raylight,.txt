A. Project Settings vs. Shot Settings (Inherit from project)
Raylight Behavior:
Project Settings define the global canvas configuration: Default Canvas Aspect Ratio (16:9, 9:16, 1:1, etc.), Target Resolution, Default Frame Rate (30/60 FPS), and Default Project Background (Solid, Gradient, or Image).
Shot Settings: Each shot has its own inspector when selected. For background, it has an "Inherit from project" toggle:
Toggle ON (Default): The shot automatically adopts project.background. Modifying project settings updates all inheriting shots simultaneously.
Toggle OFF: Unlocks a local background override specifically for that shot (with its own color picker/gradient editor), leaving other shots unaffected.
Current Codebase Gap: In src/panels/Inspector/ShotInspector.tsx, editing the background currently mutates project.background globally for all shots without an inheritance toggle. Shot in src/model/types.ts has background?: Background, but the UI lacks the Inherit from project switch.
